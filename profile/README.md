Icy is for people who keep microscopy images they own and want one named icy desk, not mixed untitled stacks. It gives you own images, a sequence list, and a short path back to a stack view you already keep. It does not replace the rest of your PC. It sits beside the files you already use.

## Inside Icy

Icy is a local Windows bioimage app with a named icy desk, a short sequence list, and a clear last handoff. It does not try to replace the rest of the PC. It sits beside images you already own and holds only the stack that is open now.
The layout stays small on purpose: one desk, one list, one path back. Extra stacks wait for their own title. Icy starts with a local profile and does not need a complex account system.

The icy desk stays on files you already keep. Untitled stacks stay off the live list.

## Quick Start with Icy

1. Open the last Icy session on images you own, not a new empty stack.
2. Read the icy desk and the last handoff.
3. Finish one visible stack view inside Icy.
4. Write what changed, then close with a shorter sequence list than you found.
5. If the desk feels crowded, drop anything that belongs to a different file.
6. Leave the icy desk on images you already keep.
7. If a stack is not yours, leave it off the live list.
8. Keep the icy desk on a sequence you already own.
